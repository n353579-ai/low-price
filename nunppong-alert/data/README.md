# 단속카메라 데이터

앱에 들어 있는 `app/src/main/assets/cameras.grid.txt` 는 공공데이터포털
**전국무인교통단속카메라표준데이터**(경찰청, https://www.data.go.kr/data/15028200/standard.do,
데이터 기준일자 2026-06-10)를 `tools/convert_cameras.py` 로 변환한 것입니다.
원본 이용 조건은 공공데이터포털의 해당 데이터셋 이용 조건을 따릅니다.

새 CSV로 갱신하려면 이 폴더(`nunppong-alert/data/`)에 CSV를 올리면 빌드 때 자동 변환됩니다.

변환 규칙: 제한속도가 있는 행을 과속 단속으로 보고(주정차 전용 제외), 좌표 없는 행과 같은 위치 중복을 제거합니다.
컬럼명: 위도, 경도, 제한속도, 단속구분 (방향각 컬럼은 없음).
